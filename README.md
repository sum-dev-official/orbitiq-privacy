## 🚀 How to Host on GitHub Pages in 2 Minutes (GitHub এ লাইভ করার সহজ নিয়ম)

### Step 1: GitHub এ নতুন Repository তৈরি করুন
1. আপনার GitHub একাউন্টে যান: [github.com](https://github.com)
2. উপরে ডানপাশের **`+`** আইকনে ক্লিক করে **New repository** সিলেক্ট করুন।
3. **Repository name** দিন: `orbitiq-privacy`
4. অবশ্যই **Public** সিলেক্ট রাখবেন।
5. **Create repository** বাটনে ক্লিক করুন।

### Step 2: ফাইলগুলো আপলোড করুন
1. তৈরি হওয়া রিপোজিটরির পাতায় **"uploading an existing file"** লিংকে ক্লিক করুন।
2. আপনার কম্পিউটারের এই `orbitiq-privacy` ফোল্ডারের ৩টি ফাইল ড্র্যাগ করে ছেড়ে দিন:
   - `index.html` (Privacy Policy)
   - `terms.html` (Terms of Service)
   - `deletion.html` (Data Deletion Portal)
3. নিচে সবুজ রঙের **Commit changes** বাটনে ক্লিক করুন।

### Step 3: GitHub Pages চালু করুন (Enable Pages)
1. Repository এর উপরের **Settings** ট্যাবে যান।
2. বামপাশের মেনু থেকে **Pages** সিলেক্ট করুন।
3. **Build and deployment** সেকশনের নিচে:
   - **Branch**: `None` থেকে পরিবর্তন করে `main` সিলেক্ট করুন।
   - ফোল্ডার: `/ (root)` থাকবে।
   - পাশে থাকা **Save** বাটনে ক্লিক করুন।
4. 🎉 **সফল!** ১ মিনিটের মধ্যে আপনার ওয়েবসাইট লাইভ হয়ে যাবে:
   ```
   https://sum-dev-official.github.io/orbitiq-privacy/
   ```
